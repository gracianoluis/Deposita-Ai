# Deposita AI

O **Deposita AI** é um projeto de banco fictício integrado com Inteligência Artificial utilizando **Ollama**.  
A proposta do sistema é simular um agente bancário inteligente capaz de interpretar comandos do usuário e executar operações financeiras básicas, conectando a aplicação a um banco de dados no **Supabase**.

O objetivo principal do projeto é unir conceitos de **Java**, **banco de dados**, **DAO**, **SQL** e **IA local**, criando uma aplicação onde o usuário pode interagir com o agente de forma mais natural, como se estivesse conversando com um atendente bancário virtual.

## Funcionalidades principais

- **Transferência via Pix**  
  Permite realizar transferências entre contas cadastradas no sistema, simulando uma operação de Pix.

- **Depósito de dinheiro**  
  Permite adicionar valores ao saldo da conta do usuário.

- **Consulta de extrato bancário**  
  Exibe o histórico de movimentações realizadas na conta, como depósitos e transferências.

- **Consulta de saldo**  
  Permite consultar o saldo disponível na conta do usuário.

## Tecnologias utilizadas

- **Java**
- **Ollama**
- **Supabase**
- **PostgreSQL**
- **JDBC**
- **DAO Pattern**

## Objetivo do projeto

Este projeto tem como objetivo praticar a criação de uma aplicação bancária simples com persistência em banco de dados e integração com um agente de Inteligência Artificial.  
A ideia é que o usuário consiga solicitar ações como “consultar meu saldo”, “depositar dinheiro” ou “fazer um Pix”, e o sistema interprete essas intenções para executar a operação correspondente.
